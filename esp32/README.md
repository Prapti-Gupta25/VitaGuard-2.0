# VitaGuard ESP32 Prototype

This folder contains the prototype firmware structure for the VitaGuard wearable.

## Current Prototype

The firmware demonstrates:

- ESP32-based monitoring structure
- Gas, temperature, heart-rate and motion data handling
- Dynamic risk-score calculation
- Local buzzer alert
- Serial monitoring output

The current firmware uses simulated sensor values because the physical sensor modules are not connected to this prototype version yet.

## Planned Hardware

- ESP32
- Gas sensor
- Temperature sensor
- Vital parameter sensor
- IMU / motion sensor
- LoRa module
- Buzzer
- Haptic motor

## Future Integration

The prototype can be extended with actual sensor modules, LoRa communication and the complete wearable hardware setup as the project progresses.
